### Aufgabe 01 - Grundbegriffe

> a.) Wie lang (in Terminalsymbolen) ist der kürzeste Satz in MicroJava, der mindestens ein *Tilde (“∼”)* enthält? Geben Sie ein Beispiel für einen Satz dieser Länge an. Der Satz muss nur syntaktisch korrekt (entspricht der Grammatik) sein, nicht semantisch (hält alle Kontextbedingungen der Sprache ein). Beispielsweise ist $x = x + 1$, ohne $x$ zuvor zu definieren, eine syntaktisch korrekte Zuweisung, semantisch korrekt ist sie aber nicht.

Die benötigten "Komponenten", um so einen Satz zusammenzubauen finden sich in:

- `Program`

- `MethodDecl`

- `Block`

- `Statement`

- `Designator`

Der "Pfad" sieht so aus:

```java
"program" ident "{" {MethodDecl} "}" // Program
"void" ident "(" ")" Block // MethodDecl
"{" {Statement} "}" // Block
Designator "++" ";" // Statement
ident {"[" "~" number "]"} // Designator && Expr/Term/Factor
```

Das ganze "ausprogrammiert" würde dann so aussehen:

```java
program P {
    void method() {
        x[~1]++;
    }
}
```

Es werden also ingesamt **17 Terminalsymbole** benötigt.

> d.) Welche terminalen Anfänge und Nachfolger haben die Regeln *MethodDecl, AssignOp* und *CondTerm*? Bitte die finalen Antworten komplett ausschreiben (i.e., jeweils ein Set an TS)

**MethodDecl:**

- `First(MethodDecl) = First(Type), "void", "(" = ident, "void", "("`

- `Follow(MethodDecl) = "}"`

**AssignOp**

- `First(AssignOp) = "=", "+=", "-=", "*=", "/=", "%="`

- ```
  Follow(AssignOp) = First(Expr)
                   = "-", First(Term)
                   = "-", First(Factor)
                   = "-", First(Designator), number, charConst, "new" ident, "("
                   = "-", ident, number, charConst, "new" ident, "("
  ```

**CondTerm**

- ```
  First(CondTerm) = First(CondFact)
                  = First(Expr)
                  = ident, number, charConst, "new" ident, "("
  ```
- ```
  Follow(CondTerm) = "||", Follow(Condition)
                   = "||", ")"
  ```

### Aufgabe 02 - Konstruktion einer Grammatik

> Geben Sie eine EBNF-Grammatik an, die folgende Beschreibung abdeckt. Es handelt sich dabei um eine fiktive Schachnotation. Bilden Sie dabei beliebig viele Non-Terminalklassen, mindestens jedoch eine für jedes **fett** geschriebene Wort.
> 
> Ein **Spiel** setzt sich aus mindestens einem **Zug** zusammen, wobei Züge durch Beistriche (“,”) getrennt sind. Nach dem letzten **Zug** steht ein Strichpunkt (“;”).
> 
> Ein **Zug** beginnt mit einer **Figur**, gefolgt von einer **Position** (Startposition). Darauf folgt ein Bindestrich (“-”), gefolgt von einer weiteren **Position** (Zielposition). Sollte durch den **Zug** eine **Figur** geschlagen worden sein, folgt ein $“x”$. Unabhängig davon, ob eine **Figur** geschlagen wurde, folgt gegebenenfalls die Information, ob der Gegner Schach ( $+$ ) oder Schach-Matt ( $\#$ ) steht. Ein Spieler kann nicht gleichzeitig Schach und Schach-Matt stehen.
> 
> *Beispielzüge:* Ka1-a2, Qf5-h7x#, Pb2-c3x, Rh1-h6+, Bb5-d7x+
> 
> Eine **Figur** ist entweder ein König (“K”), eine Königin (“Q”), ein Turm (“R”), ein Läufer (“B”), ein Springer (“N”), oder ein Bauer (“P”).
> 
> Eine **Position** ist eine **Spalte**, gefolgt von einer **Zeile**.
> 
> Eine **Spalte** ist ein Buchstabe zwischen a und h (a, b, c, d, e, f, g, h).
> 
> Eine **Zeile** ist eine Zahl zwischen 1 und 8 (1, 2, 3, 4, 5, 6, 7, 8).

```
Game = Move {"," Move} ";"
Move = ChessPiece Position "-" Position ["x"] ["+" | "#"]
ChessPiece = "K" | "Q" | "R" | "B" | "N" | "P"
Position = Column Row
Column = "a" | "b" | "c" | "d" | "e" | "f" | "g" | "h"
Row = "1" | "2" | "3" | "4" | "5" | "6" | "7" | "8"
```
